# Golden files

| File | Status |
|---|---|
| `format2_v0.5.json` | Hash format 2. Generated by Rust (`cargo run --bin emit_golden_format2` in nauticalab/starfix) and copied here byte for byte. Every vector and relation is asserted by `tests/test_golden_parity_format2.py`. Never edit. |
| `format1_to_format2.json` | Every format-1 golden or pinned value of the Rust repository with its format-2 value (Rust-generated, copied byte for byte). Used to move this repository's hand-coded test literals to format 2. |
| `python_literals_format1_inputs.json` | Inputs of this repository's hand-coded format-1 test literals that `format1_to_format2.json` did not cover, recovered from the calls that produced them, so that Rust could supply their format-2 values. |
| `include_metadata_v0.3.json` | Format-1 golden file (starfix ≤ 0.4), kept unchanged. Asserted against the legacy 0.4 mode (`tests/test_legacy_v0_4_golden_parity_metadata.py`). |
